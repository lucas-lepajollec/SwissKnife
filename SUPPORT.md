# Support

Start with the [README](README.md) and the [documentation](https://docs.swissknife.lucas-homelab.fr). Search existing [GitHub issues](https://github.com/lucas-lepajollec/SwissKnife/issues) before opening a new report.

For conversion problems, include the input and requested output formats, browser and OS, file size, deployment method and sanitized FFmpeg output. Do not upload private media merely to demonstrate a bug; use a small redistributable sample or describe how maintainers can create one.

Use the unsupported-format template for a missing format or codec and a feature request for a broader workflow proposal. Questions already answered in the documentation may be closed. Suspected vulnerabilities or any unexpected file upload must follow [SECURITY.md](SECURITY.md), not a public issue.
